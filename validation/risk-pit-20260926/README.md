## 已实现的边界

|环节|行为|失败处理|
|---|---|---|
|组合优化|预算、单标的、行业、换手和线性因子上下限联合求解|不可行或不收敛时拒绝，不返回破坏其他约束的权重|
|风险输入|完整持仓暴露、有限收益、PSD协方差、成本估计、必需漂移因子|缺失不能填零；迟到旧观测不能覆盖新观测|
|风险模型|期初可得X、因子收益、F、D、资产协方差和风险分解|时点、覆盖、秩、条件数或矩阵一致性不满足时拒绝|
|风险收益|原始价格加此前已公告的公司行动权益|不使用未来复权版本估计历史风险|
|信号证据|中性化、截面排序、延迟顺序与实际策略一致|训练证据的延迟和表示不匹配时拒绝|
|整手目标|重新检查组合限制、绝对/主动暴露、跟踪误差|拒绝目标并记录原因|
|实际持仓|每日检查真实账本，超限锁存，撤单并释放预约|按配方停止或只减仓清算，不自动重入|
|报告|保留全部候选、失败、测试折和风险事件|有风险告警的收益不能被包装为无约束成交表现|

跟踪误差目前是整手目标和实际持仓的执行门禁，未进入优化器的二次约束。清仓仍受交易规则、行情、流动性和已配置复杂风险限制约束；发出清仓请求不代表即时成交。

纯现金目标和纯现金实际状态的基准相对TE/主动因子限制保留为warning；它们不能因股票基准仍有波动而禁止全部退出。非空持仓、绝对因子限制和模型有效性检查不放松。这一语义修复来自r2真实账本复核，原始结果和修复前登记均保留。

## 真实数据与模型范围

研究池固定为510300、510500、159915和588000。它覆盖不同股票指数ETF，但没有因此扩展为全市场A股、动态ETF全集、期货或加密货币真实研究。期货价差和加密基差继续保留既有独立冻结样例环境。

行情通过AKShare适配器访问Sina历史成交价，分红与公告来自EastmoneyF10；交易所和基金发行材料用于核证主表与规则。每个来源的实际捕获时间、URL和哈希必须留存。当前版本历史数据不等于供应商逐日归档版本，静态主表也不等于完整停复牌、涨跌停状态和动态全集。

本次真实研究采用`statistical_proxy`的market常数因子，不把ETF持仓等同于股票风格暴露。框架可以消费真实PIT描述子，计算`Σ=XFXᵀ+D`、基准相对暴露和风险贡献，但尚未具备完整Barra描述子体系、行业约束加权回归、风险校准或ETF成分穿透，也不是MSCI授权模型。

## 如何理解证据

滚动训练、隔离和测试窗口可以检查固定方法在历史数据上的表现。由于数据与观察池在本次开发中已被看到，这类结果标记为历史滚动样本外，不能称为完全未触碰的前瞻样本。

真正的前向观察必须先冻结代码、参数、候选、未来起止日期与数据前缀，再等待交易日结束后追加同一账本的观察。注册时的已观测样本数是零。不能回填未来结果，不能根据后续表现偷偷更换策略或起点；修订输入导致旧前缀变化时必须保留阻断证据。

## 后续模型发展要求

1. 补足具备原始披露与修订时间的财务、流通市值、行业、动态成分和交易状态源，先验证覆盖与使用权限。
2. 为规模、价值、成长、质量、杠杆、流动性、动量与残差波动率建立可复算的描述子定义，检验去极值、标准化和中性化时点。
3. 在足够宽的真实证券截面上估计行业与风格因子收益，处理行业共线性、回归权重、残差异方差和因子相关。
4. 用未来实现风险检验预测波动率、跟踪误差和风险贡献校准，固定评估窗口并保留所有失败版本。
5. 扩展ETF成分穿透、容量与冲击成本后，才评估实盘适用性；当前仓库没有券商实盘下单链路。
