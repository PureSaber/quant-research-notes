# 择时Studio入口与原生研究证据验收

2026-10-04，择时原生只读预检接入Studio。当前共十个模板、九个业务预检入口。本项完成P1.1的一项增量；完整新手流程、A股真实缓存GUI、基金嵌入兼容性及总计划其他事项继续，未增加独立前向样本。

## 实现与口径

[Timing#8](https://github.com/PureSaber/quant-timing/pull/8)增加独立成本系数文件，仅允许0至10的有限数值，默认1保持原费率与冲击系数。原配置相对路径保持不变，覆盖文件参与输入身份和变化核验，不修改模型、资本和滚动窗口。

原先仓位决定、分折CSV和CLI输入上下文没有全部受标准清单保护，无法作为统一页面的核验依据。现在把发布决定、因果审计、原生分折记录、CSV哈希和CLI上下文加入受保护的metrics；原收益与CSV计算不变，旧产物不补写。

[Studio#14](https://github.com/PureSaber/quant-studio/pull/14)使用所选上游Python核验标准产物后生成展示视图。页面分别呈现发布状态、滚动测试折与描述性全区间策略/基准曲线，后者含预热期，不代表滚动样本外收益。两条曲线同日期、期初净值1，单位本金的份额、金额、费用及期货名义敞口按原生语义展示。

`hold_previous`显示保留旧仓位且未发布新系数；`blocked`保留原生原因及测试折，不生成成功曲线。结构预检、历史计分和最新发布门禁是不同判断。此入口没有更新既有账户，也不发送真实订单。

展示视图绑定原生产物与展示文件的摘要；再次打开时重读核验。文件缺失、内容变化或未核验的曲线均拒绝显示，不使用缓存代替。哈希关系不是数字签名，不独立认证行情真实性。
