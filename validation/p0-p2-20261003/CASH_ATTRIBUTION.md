# 四ETF现金证券账本归因

2026-10-03，冻结r4四候选的全部12个测试运行完成原生账本归因。对应[Report Hub#24](https://github.com/PureSaber/quant-report-hub/pull/24)，实现提交`ccaf474`。本项完成P1.2中的现金证券会计分解；后续[六维反事实与三基准比较](COUNTERFACTUALS.md)也已验收，独立参考价滑点和现金/趋势的进一步独立干预仍待完成。

## 根因与实现

既有M5归因要求来源提供受控组件。真实QExec产物保留原生maker/taker合并费用，没有独立的来源归因表；快照按事件保存、收益按日保存，而且包含分红应收与支付两个阶段。直接改费用名称无法补足这些会计语义。

新增`quant-report cash-attribution --run-dir <source> --out-dir <new-report>`，先经Lab完整验证v2清单、hash、schema和血缘，再重建期初现金、逐笔成交、费用、公司行动、持仓数量及分红应收。报告按来源收益时点划分期间，包括首日收益；要求每个事件和期间精确守恒：

```text
NAV = 现金 + 证券估值 + 分红应收
净损益 = 估值与成交损益 + 公司行动收益 + 费用现金影响
估值与成交损益 = 证券市值变化 + 买卖/终止兑付现金
公司行动收益 = 分红现金 + 分红应收变化
```

分红确认进入收益，支付只将应收转为现金；清仓不丢弃尚未支付的应收。费用保留原生分类与符号，可处理返佣；不臆造佣金、印花税或滑点分类。金额用Decimal精确计算，来源浮点净收益率单独使用`1e-12`误差门限。

输出证券损益、期间对账、事件对账、费用明细四份CSV、HTML报告及带SHA-256的manifest。输出只能写入源运行目录之外的新目录；损坏或会计不一致不发布。既有M5组件归因未放宽。

## 实际验收

[机器可读回执](evidence/cash-attribution.json)绑定来源study、每份源manifest、报告manifest和实现提交。原生CLI覆盖base、buy_hold、cost_2x、delay_1各3折，共3,048个事件快照、756个候选期间和212条费用；所有事件与期间残差为零。511份冻结研究文件的hash、修改时间及目录清单均保持不变。

756条期间记录是4候选共享189个测试日期，不是756个独立市场样本。未重新回测、未增加自然前向日期、未改变r4账户或登记。

基础策略三折的金额分解如下，各折期初资金均为100万元：

|测试折|估值与成交损益/元|分红收益/元|费用现金影响/元|净损益/元|
|---|---:|---:|---:|---:|
|2025-12-02—2026-03-10|26,143.70000|13,814.00000|−1,432.92068|38,524.77932|
|2026-03-11—2026-06-11|12,488.80000|0|−1,256.88643|11,231.91357|
|2026-06-12—2026-09-09|−84,135.20000|6,928.50000|−967.96591|−78,174.66591|

各折独立账户的金额不能直接合计为连续账户复合收益。第三折的估值与成交损益为主要负项；仅这张会计表不能区分证券选择、持仓规模、风险停机、现金机会成本和成交滑点各自的模型反事实贡献。

本机完整测试184项通过、5项既有条件跳过，总覆盖率89.56%；新归因模块纯分支覆盖率98.68%，纳入90%核心门禁。新增33项覆盖首日费用、拆股、分红应收、卖清后到账、直接现金分红、终止兑付、返佣、多证券、纯现金、大整数、文件损坏和账本不一致。实际浏览器显示首折汇总和逐日对账；截图仅保存在本机，回执记录hash。

## 剩余工作

- 绑定已冻结行情、成交时点与可得时点的独立参考价格，拆分成交价格中的滑点；不从成本参数倒推后冒充独立参考。
- 六维单项干预和三个独立基准已在新研究定义中完成，见[反事实研究](COUNTERFACTUALS.md)。继续分离现金预算、趋势筛选等未识别因素；保留全候选与未解释/交互残差，不借新回放修改冻结前向参数。
- 继续独立自然前向；会计守恒不证明历史市场规则完整、可投资性或策略有效性。

新命令仅适用于单账户、单策略、同币种、单位乘数的多头现金证券。保证金、FX、外部入出金和未知账本事件拒绝处理，其他资产须按其原生语义单独验收。
