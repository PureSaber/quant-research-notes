# 期货与Crypto离线样例接入Studio

2026-10-04，Studio新增期货双腿及Crypto基差模板，共八个模板、七个业务预检入口。两条入口仅消费上游随附的合成/脱敏离线样例，不接受外部行情目录、不连接交易所，不增加真实市场或独立策略证据。P1.1整体继续进行。

## 软件交付与口径

- [Crypto#10](https://github.com/PureSaber/quant-crypto-basis/pull/10)增加显式初始资金、币种和maker/taker参数；预检与回放使用同一配置。合并提交为`02acfeb6227d8f61243b908846592af4e5b70365`，96项测试通过，覆盖率96.10%。
- [Studio#12](https://github.com/PureSaber/quant-studio/pull/12)增加模板、原生事件净值和七类账本展示。合并提交为`6207b8eccd5488e028139ba5e7abf4d63c9704ef`，与最终PR提交`555a44c3f223b68e1f0c9a15795f64f6d56ed234`源码树一致。
- 期货上游固定`f01d6afd87ca0556d6e2f44e522cfecbf00cad56`。两个应用保留各自独立Python环境；预检、运行及展示转换使用同一解释器。

期货模板回放固定开平仓、换月及结算计划，可设置初始资金和随机种子。Crypto另可选择Binance/OKX离线来源及maker/taker。资金按文本传递，支持最多8位小数。

两个上游的收益列含义不同，不能统一累乘作为账户净值；此前Crypto配置还未显式记录初始资金。本次由上游保存实际本金与币种，Studio通过冻结QLab完整核验standard/v2，直接读取portfolio_snapshots中的定点净值，保留UTC事件时点和毫秒。展示转换不重算现金、持仓或保证金。

账户快照、持仓、委托、成交、保证金、费用与资金费、现金账本分别投影成CSV。整数与精度转换使用精确十进制，包含可空价格和保证金共用精度；表格中文列名保留原字段提示，预览前12行并提供完整下载。转换前后核对原始清单、哈希和修改时间，输出与standard/v2分开。微小非零收益按需增加精度，避免显示成负零。

## 跨平台根因修复

初次CI的[37144225083](https://github.com/PureSaber/quant-studio/actions/runs/37144225083)有两个Windows新增上游检查失败。旧实现从CLI启动器所在目录推断Python路径；Windows全局安装把启动器放在Scripts而Python位于上一级，本地虚拟环境没有暴露这个假设。

修复后两个模板直接使用选定Python的模块入口，展示转换复用同一解释器，删除目录推断。功能修复提交`b80abeefd6b770e18eed58f5ea54c367f31fb10c`的[14组检查](https://github.com/PureSaber/quant-studio/actions/runs/37144638367)全部通过；最终提交只修正文档计数，其[14组检查](https://github.com/PureSaber/quant-studio/actions/runs/37145690355)也全部通过。Windows/Linux单测检查同时通过，保留原失败记录。
