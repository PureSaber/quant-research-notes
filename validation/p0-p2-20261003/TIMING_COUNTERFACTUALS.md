# 择时仓位与风格的固定反事实

2026-10-04完成12组历史研究的32个原生候选回放。此项推进P1.2的限定模型干预、联合交互和账本解释；完整P0—P2仍在进行中。没有新增独立前向日期，也没有改变r4/r5环境或前向候选。

## 固定协议与解释范围

总计划及各候选族的协议在执行前保存真实时间、配置和输入哈希。历史结果此前已经观察，因此执行前冻结不构成盲测或独立前向登记。

- base沿用原配置。仓位干预只把rules三档或其他模型的floor/cap统一为1，保留原特征、预热和后续约束。
- 风格干预只把tilt改为0.5，保留组权重、活动度基准和偏离上限；联合候选同时实施两项。
- 原现金/保证金/期货、估值和宏观、外部仓位、日变动和回撤限制、成本系数不变。各路径完整重算，约束和交易对干预的响应属于总模型效应。
- 无风格模块时只运行base与仓位干预，风格效应与交互为不适用。对照run_id后缀只改变身份。
- 每个候选保留原生历史截断检查，不扩大为全日期因果证明。任何必需候选失败，整个候选族不生成效应结论，失败记录保留。
- 所有候选包括base均不发布position_scale或portfolio_overlay。

因此“取消仓位模型降档”不等于从首日开始最终满仓；“取消风格信号倾斜”不等于被动等权市场组合。

每个测试折沿用原决策日及下一收益日计分，归因期初单独归一，但不重新建立账户、不拼接重叠窗口。干预效应为干预净收益减base；联合交互为joint−position−style+base。资产、现金、保证金、期货与模型费用的贡献差必须逐项加总到效应。
