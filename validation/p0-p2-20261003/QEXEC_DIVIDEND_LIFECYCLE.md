# 分红生命周期执行与完整事实回放

2026-10-04。[QExec#22](https://github.com/PureSaber/quant-execution/pull/22)已合并，审查head为`f175158d2a9f57887db36d308d678aa21c2ab4ff`，合并提交为`384025aa76aae79b30c258cd5eef6eb068a2ce11`。本项完成P0.3b的执行层软件增量；HK应用适配及真实账户验收继续。

新增独立的权益、发行人换汇和实际付款三阶段API，以稳定分红ID和阶段标识处理幂等，保存父状态哈希和不可改写的已接受事实。权益阶段核对除息时真实账本数量与外部权益证据，之后卖出不改变原权益数量；负持仓、衍生品分红、迟到权益和倒退账本时间明确拒绝。失败恢复完整内存状态。

金额以精确分数计算到整户聚合边界，再应用有证据的账户舍入政策。发行人换汇采用公布付款额，保留源单位、原近似标记、有限精度汇率与精确差值；没有发行人舍入契约时，关系标记为`unverified_no_rounding_contract`。不会强制公布金额与有限精度汇率代数恒等，也不猜测容差。

`EVIDENCED_PIT`覆盖整个账户的应收、外币现金、NAV、风险、清算及残差核验。发行人换汇与估值FX分别使用，缺失、未来或歧义FX拒绝估值。历史汇率不能与未来持仓状态拼接。普通查询只读，显式估值记录保留完整选中FX、截止时间、结果、操作顺序和交易数量。

生产模式分别核验权益basis、首次采用的付款政策和实际支付。调用方自行填写认证标志不能取代受信验证器。`trusted_verification_scope`只列实际核验事实，`market_admission_certified`始终为false；本次软件样例未认证真实账户。

新版manifest`1.1.0`增加分红记录，先封存完整账本副本，再按实际业务顺序重放开仓、现金、mark、成交及费用、公司行动、PIT FX、分红阶段和估值。最终持仓批次与mark仅用于比较。发布正式manifest之前验证物理/逻辑哈希、重放结果及账本摘要；失败目录标记不可用，只能换新目录重新导出，原账本事实保留。

独立复核推动修复了三类时间旁路：

- 未来生效的政策提前参与权益舍入；阶段采用事实须同时满足可得与生效边界，权益政策两时间均不得晚于`ex_at`。
- 未来生效的币种选择使执行越过请求cutoff；账本实际应用时间不能超过该cutoff。
- 幂等快速返回先于生效检查，向更早cutoff返回未来旧记录；时间验证现覆盖重复调用，合法相同或更晚cutoff仍复用原事实。
