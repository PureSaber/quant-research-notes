# 择时反事实候选族接入Studio

2026-10-04，固定仓位与风格反事实已通过[Studio#16](https://github.com/PureSaber/quant-studio/pull/16)接入统一入口。
平台现有十一个模板、十个业务预检入口。此项完成研究运行、原生核验与结果展示；完整P1.1、P1.2和P0—P2继续。

## 行为与核验边界

普通择时结果只有一个研究集合，并受最新仓位发布门禁约束。反事实输出包含多个候选，各候选有意禁止发布仓位，不能把其中的base或普通发布退出码当成整个候选族的结论。

新增`timing-counterfactual`模板读取已有YAML，先调用原生只读预检，再按相同配置运行固定候选族。无风格模块时比较两候选，有风格模块时比较四候选。页面不提供参数搜索或成本覆盖，不改原配置或已有账户；普通择时发布门禁保持原样。

所选上游Python调用原生核验器，从候选产物重算家族报告；核验前后原生文件集合和SHA-256必须一致。Studio保存独立展示文件，页面和下载均再次检查完整文件集合。缺文件、内容变化、额外单研究展示文件、额外仓位发布文件及数据性质被独立修改都会被拒绝。路径越界和符号链接不进入展示。

研究完整时显示候选状态、描述性全区间、各测试折效应、联合交互及分量差；各折不重新建仓，不拼接重叠日期。必需候选失败时保留原因和原生报告，族级结论不可用。所有反事实候选禁止生成下游仓位发布文件。
