# 统计套利原生只读预检与Studio入口验收

2026-10-04，统计套利新增独立只读预检，并接入Studio已有配置文件入口。当前Studio共九个模板、八个业务预检入口。P1.1整体继续进行，本项不增加独立策略样本或市场业务认证。

## 实现与业务口径

[StatArb#5](https://github.com/PureSaber/quant-stat-arb/pull/5)让预检与原生运行共用配置解析、价格/全收益/ADV对齐和滚动窗口检查。预检不选对、不拟合、不回放、不执行泄漏审计，也不写出策略结果。输入在准备或运行期间改变时拒绝导出；覆盖来源文件的输出目录被拒绝。

[Studio#13](https://github.com/PureSaber/quant-studio/pull/13)正式支持文件输入，选择原YAML研究配置，仅另存预算和成本系数。两系数默认1，不调整筛选或交易阈值；相对数据路径仍以原配置目录解析。修复页面初始预览硬编码港股环境变量的根因，基金、美股和统计套利均读取各自声明来源。

来源由`source.evidence_kind`显式声明，旧配置缺少该字段时显示未声明，不根据文件名或旧`source.mode`猜测。真实GUI使用原配置的独立副本，仅补回顾性来源声明，原模型参数及价格输入保留。

净值从1开始，采用原生滚动测试计分路径并包含平仓成本。持仓、订单quantity及market_value表示研究权重；订单是研究目标，费用是收益比例。页面使用对应表名和中文列名，不显示真实股数或货币本金，也不把标准收益文件的零基准占位列当成市场基准。
