## 宿主异常对照

使用历史保留的[静态父页](reproductions/fund-embed/embedded.html)和[静态子页](reproductions/fund-embed/child.html)，在同一浏览器和本机HTTP临时服务执行新对照：父页和直接子页的DOM脚本数均为0，静态iframe仍记录同一错误，直接子页error/warn为空。基金原生报告嵌入同样报错，而新建直接报告标签无错误。旧标签累计日志没有当成新直接报告的错误，直接场景使用新标签隔离。

错误为`Uncaught TypeError: Failed to execute 'observe' on 'MutationObserver': parameter 1 is not of type 'Node'.`。浏览器回执没有给出具体来源URL或调用栈；当前证据支持宿主嵌入环境方向，不能确定责任组件。本轮没有覆盖MutationObserver、吞异常或删除iframe。异常不阻止本轮图表显示，但完整兼容性仍须取得宿主来源并修复后重验，见[历史及当前诊断](FUND_EMBED_DIAGNOSTIC.md)。
