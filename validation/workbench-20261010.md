# 工作台日常使用阶段

日期：2026-10-10。目标为完整工程链路及随时开展研究，不以策略盈利或持续有效性作为工程验收条件。

## 已交付的入口

- 数据集登记、文件身份验证、港股日线显式 API 采集/刷新；新快照不覆盖旧输入。其他市场接入已有原生输入，不宣称全市场自动获取。
- 中文配置表单、按行名单、港股证券勾选和交易规则编辑、高级原生配置入口。
- 不可变方案历史与参数差异、独立实验笔记、全部历史搜索、2–4 次结果比较；日期/来源等口径不一致不合并曲线。
- 自定义 Python 模块 init/register 命令：隔离环境安装、本地预检、发布模块声明、连接网页。
- 单实例服务监护、异常重启、当前用户登录后自启、证书提醒、空闲定时备份及 SHA-256 恢复核验。

## 验收边界

真实港股链路使用新浪接口的腾讯与汇丰行情，2025-07-02 至 2026-09-25，原生预检返回 614 行、2 个标的。两组费用配置完成运行，并在网页验证版本差异、实验笔记和结果比较。公司行动、历史名单及历史交易规则限制仍按原生报告披露；不认证策略有效。

独立新建的 Python 模块完成脚手架、注册预检、网页方案保存及执行。工程回归、生命周期和归档恢复的最终机器回执保存在本机本阶段验收目录，不向源码仓提交行情、凭据或运行数据。

本机作为服务器，已完成 Tailscale 私有组网、HTTPS 证书与客户端信任、工作台登录和受控端口访问配置。真实第二台电脑已成功登录；Clash Verge Rev 的系统代理与 TUN 同时开启时，浏览研究方案、结果列表及原生报告均成功，服务端请求记录返回 200。仅确认本次网络条件下的访问，尚未切换外部网络、在客户端提交新研究或完成手机验收。代理绕过须同时检查系统代理与 TUN；本次取消了未通过配置校验的 TUN 排除修改，不把它列为已生效的规则。

登录问题修复：浏览器后台请求 favicon 曾重置登录表单 nonce，现改为不设置 Cookie 的 204 响应；有效登录、过期/不匹配 nonce 与错误密码均有回归覆盖。收尾复跑 Studio 完整测试为 307 项通过，Ruff 检查、格式检查与 pip check 通过。服务异常重启及备份恢复已验收；登录自启已登记，但真实注销/重启后自启尚未演练。

当前用户自启发生在登录 Windows 后；电脑睡眠/关机时不可用。Windows 中已有的 Python 放行规则仍保留，本次受控端口访问还依赖 Tailscale 策略约束，不将防火墙单独表述为完整隔离。历史冻结研究目录、真实账户和历史发布认证继续保留。

定时备份覆盖工作台状态与工作台管理的快照，不是整机镜像；外部数据、独立源码环境及密钥要分别保存。未完成的 A 股历史披露、基金真实业务单据、国内 L2 授权等资源门禁不因网页升级而关闭。
