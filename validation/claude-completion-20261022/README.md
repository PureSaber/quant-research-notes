## 已验证的实现

- 研究门槛：点估计、原生工程 A、未来研究 B、晋级 C 分开。B 使用原登记时间、
  冻结日期/目标/基准/成本、配对区块自助法、预期改善幅度和可检测性；所有区块长度
  均需支持结论。当天尚不可知的校准日收益及收盘前的最后一天证据不能使用。
  方法采用平稳性和平方根样本数近似，不声称保证检测功效。历史回放不能取得 B/C。
- 510500 拆分：使用南方基金原始公告的精确 **1.14539**，按账户向上取整。
  2022-08-26 收盘登记，日频回放约定 16:00 入账，2022-08-29 为拆分后交易/可卖日。
  16:00 是日终模型约定，不是伪称取得了登记系统的精确到账时间。
- 真实历史行情的原生短回放：100 份变为 115 份，100,000 份变为 114,539 份；
  两组每笔复式记账均平衡，重复回放结果相同。供应商四位小数 1.1454 不参与记账。
  该短回放用于软件验收，不是新策略研究，也不计入 A/B/C。
- 十个现金分红事件均通过原生公告日期配对，并与新浪累计分红增量核对一致。
  原始现金、份额事件共同重算复权；不会在已复权前收盘价上重复扣减现金。
- 优化失败后逐项核验当前持仓；证据未知或不合规就停止并取消挂单。后续风险事件
  不能将该停止转成自动卖出。发布率、原因和最长连续无目标区间单独报告。
- 故障分级通过真实试验登记/失败回执/findings 链路：六类 hard stop、持仓估值、
  权益、优化失败、候选缺价及规则等十七类保守上下文注入，全部保持失败且不获得验收计数。
  已审查模板变化另有原生刷新测试，确认记录警告且附件变化仍阻止发布。
  临时估值仍是独立只读区间分析，不能回写严格账本或授权交易。
- 新 v2 规则刷新配置只支持已审查、完整静态目录的精确模板替换，文本和链接身份
  必须相同，全部附件仍核对原始摘要。旧 v1 和冻结账户配置没有迁移。
