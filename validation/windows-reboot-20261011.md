## 首次失败与修复

首次真实重启（08:16）后，Tailscale 已运行，但工作台未启动。原因是安装进程看到的
HKCU Run 值位于应用私有注册表视图，Windows 原生启动枚举未发现工作台条目。
随后在原生用户环境注册，并核对 `Win32_StartupCommand` 可见性，连续两次验证幂等性，
另三个已有启动项保持不变。此后的手动恢复仅记为恢复成功，不计作自动启动通过。

08:30 的下一次重启请求已被系统接收，但观察期间没有新的 Windows 启动，故不计为一次
真实重启验收，也不据此断定自动启动修复失败。最终以 08:49 实际开机后的证据通过验收。

修复见 [quant-studio #34](https://github.com/PureSaber/quant-studio/pull/34)，已合并为
`13cd656773749e171f090b0a7d0e6a376c8d6c25`。安装器确认当前用户的原生启动可见性，
不再仅凭私有视图中写入成功就报告安装完成；失败会回滚目标值，并保留其他启动项。
修复提交的 26 项 CI 检查均成功，本机专项 3 项测试与 Ruff 通过。审查为实施者自审，
不冒充独立审查人的批准。安装器修复不改变已验收的冻结应用环境。
